모바일 관련 Style Settings 설정하기

## 내비게이션

```md
Style Settings
|-- flexcyon://Mobile
```

## 환경 설정 옵션

### 1.11 내비게이션 UI 되돌리기

볼트 선택기와 내비게이션을 1.11 이전 스타일로 되돌립니다.

대상 CSS 클래스: `var(--flexcyon-revert-nav-item-alignment)`

기본값: true (클래스 토글)

### 모바일에서 상태바 표시

대상 CSS 변수: `var(--flexcyon-status-mobile-enabled)`

기본값: false (클래스 토글)
