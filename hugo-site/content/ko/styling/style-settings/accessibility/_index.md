접근성 옵션을 토글합니다.

현재 옵션으로는 테마 색상 또는 전역에 대한 밝기·대비·채도 등을 설정할 수 있습니다.

전역 필터 효과에 손대기 전에 테마 관련 접근성 설정을 먼저 조정하는 편이 성능에 유리합니다.
테마 관련 설정은 테마 자체의 거의 모든 색상을 동적으로 조정하기도 합니다.

## 내비게이션

```md
Style Settings
|-- flexcyon://Accessibility
```

## 환경 설정 옵션

### 테마 색상 대비 오프셋

테마 색상의 대비 오프셋을 정의합니다.
다크 테마에서는 양수 값이 클수록 대비가 커지고, 라이트 테마에서는 그 반대입니다.

대상 CSS 변수: `var(--flexcyon-theme-contrast-offset)`

기본값: 0 (변수 슬라이더, 범위 -0.3 ~ 0.3)
> +/- 0.3을 넘는 값은 일상적으로 쓰기에 그리 적절하지 않습니다.
> 더 넓은 범위의 값이 필요하다면 알려주세요.

### 테마 색상 온도 오프셋

테마 색상의 온도(warmth) 오프셋을 정의합니다.
oklch는 순환형 색 공간이므로, 원하는 색 온도를 얻기 위한 몇 가지 팁을 소개합니다.
- 다크 모드 = 매우 차가운 배경. 차가운 색상은 -20 쪽으로, 따뜻한 색상은 130 쪽으로
설정하세요.
- 라이트 모드 = 다소 따뜻한 배경. 따뜻한 색상은 -70 쪽으로, 차가운 색상은 80 쪽으로
설정하세요.

이 범위를 벗어나면 색상이 차가워졌다 따뜻해졌다 하며 번갈아 바뀔 가능성이 큽니다.
> 값을 이것저것 실험해 보세요 ^_^.

대상 CSS 변수: `var(--flexcyon-theme-warmth-offset)`

기본값: 0

### 테마 색상 밝기 비율

테마 색상의 밝기 비율을 정의합니다.

대상 CSS 변수: `var(--flexcyon-theme-brightness-ratio)`

기본값: 1 (변수 슬라이더, 범위 0 ~ 2)

### 테마 색상 채도 비율

테마 색상의 채도 비율을 정의합니다.

대상 CSS 변수: `var(--flexcyon-theme-saturation-ratio)`

기본값: 1 (변수 슬라이더, 범위 0 ~ 5)

### 전역 밝기 비율

대상 CSS 변수: `var(--flexcyon-brightness-ratio)`

기본값: 1

### 전역 대비 비율

대상 CSS 변수: `var(--flexcyon-contrast-ratio)`

기본값: 1

> 예를 들어 OLED 화면처럼 약간 더 높은 대비를 원한다면 1에서 1.5 사이의 값을 시도해
> 보세요.

### 전역 채도 비율

대상 CSS 변수: `var(--flexcyon-saturation-ratio)`

기본값: 1

> 색상의 채도를 조정하는 데 사용합니다.
