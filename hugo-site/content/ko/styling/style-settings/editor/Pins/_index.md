핀 관련 설정입니다.

## 내비게이션

```md
Style Settings
|-- flexcyon://Editor
|   |-- Pins
```

## 환경 설정 옵션

### 스타일화된 핀 아이콘

사이드바의 핀 아이콘을 스타일화합니다.

대상 CSS 클래스: `var(--flexcyon-stylised-pins)`

기본값: true (클래스 토글)

### 실수로 핀 해제 방지

우클릭 메뉴 또는 Ctrl + W로 핀을 해제합니다.

대상 CSS 클래스: `var(--flexcyon-prevent-accidental-unpin)`

기본값: true (클래스 토글)
