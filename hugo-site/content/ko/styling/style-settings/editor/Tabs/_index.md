## 환경 설정 옵션

### 숫자 탭

탭에 순차적으로 번호를 매깁니다. 각 탭 그룹은 자체 카운터를 가집니다. RTZ 모드를 위한
설정이지만 별도로 활성화할 수도 있습니다.


대상 CSS 클래스: `.flexcyon-number-tabs`

기본값: false (클래스 토글)

### 탭 헤더 제거

탭 헤더를 제거합니다. 마우스를 올리면 툴팁이 나타나 원래 내용을 계속 확인할 수 있습니다.
RTZ 모드를 위한 설정이지만 별도로 활성화할 수도 있습니다.

대상 CSS 클래스: `.flexcyon-remove-tab-headers`

기본값: false (클래스 토글)

### 탭 헤더 컨테이너와 탭 콘텐츠의 순서 뒤집기

탭 헤더 컨테이너를 화면 위쪽 대신 아래쪽에 배치합니다. 스택형 탭에는 아무 영향이 없습니다.

대상 CSS 클래스: `.flexcyon-reverse-tab-header-container`

기본값: false (클래스 토글)

### 비활성 스택형 탭 콘텐츠 흐리게

대상 CSS 클래스: `.flexcyon-dim-inactive-stacked-tab-content`

기본값: true (클래스 토글)
