## 환경 설정 옵션

### View Header 브레드크럼 최대 너비

대상 CSS 변수: `var(--flexcyon-view-header-breadcrumb-max-w)`

기본값: 12.5 (vw)

### 모드별 View Header 제목 세로 패딩

Angled 모드 및 Powerlevel10k와 같은 모드에서의 View Header 제목 세로 패딩.

대상 CSS 변수: `var(--flexcyon-mode-view-header-title-verti-padding)`

기본값: 4 (px)

### 모드별 View Header 제목 가로 패딩

Angled 모드 및 Powerlevel10k와 같은 모드에서의 View Header 제목 가로 패딩.

대상 CSS 변수: `var(--flexcyon-mode-view-header-title-horiz-padding)`

기본값: 12 (px)

### View Header 텍스트 정렬

대상 CSS 변수: `var(--file-header-justify)`

기본값: 가운데 (변수 선택)

옵션:

- 시작
- 가운데
- 끝
- Flex 시작
- Flex 끝
- 왼쪽
- 오른쪽
- 기본 (Normal)
- 양 끝 맞춤 (Space Between)
- 주변 균등 간격 (Space Around)
- 완전 균등 간격 (Space Evenly)
- 늘이기 (Stretch)

### View Header 글꼴 크기

대상 CSS 변수: `var(--file-header-font-size)`

기본값: 작은 UI 글꼴 크기 (변수 선택)

옵션:

- 더 작은 UI 글꼴 크기
- 작은 UI 글꼴 크기
- 중간 UI 글꼴 크기
- 큰 UI 글꼴 크기

### View Header 글꼴 굵기

대상 CSS 변수: `var(--file-header-font-weight)`

기본값: 400
