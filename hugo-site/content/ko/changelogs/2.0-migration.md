---
title: "2.0 Style Settings 마이그레이터"
---

클라이언트 측 마이그레이션 도구를 사용하면 2.0 이전 버전의 Style Settings 구성을
2.0.0으로 매끄럽게 업데이트할 수 있습니다. 이 도구는 대상이 되는 flexcyon Style
Settings JSON 키-값 쌍만 수정하고 알파벳순으로 정렬합니다.
그 외의 JSON 키-값 쌍은 수정하지 않습니다.

> 이 도구는 Web Assembly(wasm)를 사용하므로, 브라우저가 wasm을 지원하는지
확인하세요.
>
> 구형 브라우저를 쓰고 있다면 [caniuse](https://caniuse.com/wasm)에서 호환성을
확인하세요. 다만 wasm은 일반적으로 널리 호환됩니다.

## 사용법

1. `Settings`로 이동한 뒤 `Community Plugins` 아래의 `Style Settings`를 클릭합니다.

2. `Export`와 `Copy to clipboard`를 클릭합니다. 그런 다음 모달을 닫습니다. Style
Settings 뷰는 열어 둡니다.

3. 클립보드의 내용을 아래 마이그레이션 도구 입력란에 붙여넣습니다.

> 또는 2~3단계를 대신해 다음 위치에 있는 `data.json`을 업로드해도 됩니다:
>
> `~/path_to_your_vault/.obsidian/plugins/obsidian-style-settings/`

**진행하기 전에 Style Settings를 반드시 백업하세요.**

4. 창 포커스를 다시 Obsidian으로 전환합니다.

5. `Import`를 클릭하고 시스템 클립보드에 있는 마이그레이션 도구의 출력을 붙여넣습니다.

6. `Save`를 클릭하면 Style Settings가 2.0 버전 형식으로 마이그레이션됩니다.

> 또는 4~6단계를 대신해 `migrated_settings.json`을 내려받아 다음 위치의
> `data.json`에 그대로 덮어써도 됩니다:
>
> `~/path_to_your_vault/.obsidian/plugins/obsidian-style-settings/`
