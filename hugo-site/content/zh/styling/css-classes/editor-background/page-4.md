# 用法

在编辑器背景中添加重复的波尔卡圆点图案. 可以在样式设置中调整大小. 


```md
cssclasses:
    - editor-circle
---

Your content will render as usual
```

## Callout 元数据提供者

主题还有一个用于波尔卡圆点背景的 Callout 元数据提供程序（在 Live Preview 和 Reading 模式下）

```md
>[!note|bg-circle] I will display as usual
> I will have a polka dot pattern background
```
