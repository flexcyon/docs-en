## 配置选项

### 视图标题面包屑最大宽度

目标 CSS 变量: `var(--flexcyon-view-header-breadcrumb-max-w)`

默认: 12.5 (vw)

### 模式视图标题垂直填充

Angled 和 Powerlevel10k 等模式下视图标题的垂直填充.

目标 CSS 变量: `var(--flexcyon-mode-view-header-title-verti-padding)`

默认: 4 (px)

### 模式视图标题水平填充

Angled 和 Powerlevel10k 等模式下视图标题的水平填充.

目标 CSS 变量: `var(--flexcyon-mode-view-header-title-horiz-padding)`

默认: 12 (px)

### 视图标题文本对齐

目标 CSS 变量: `var(--file-header-justify)`

默认: Center (中心) (类选项)

选项:

- Start
- Center (中心)
- End
- Flex Start
- Flex End
- Left (左边)
- Right (右边)
- Normal (默认)
- Space Between
- Space Around
- Space Evenly
- Stretch

### 视图标题字体大小

目标 CSS 变量: `var(--file-header-font-size)`

默认: 小 (变量选项)

选项:

- 更小 (UI 字体大小)
- 小 (UI 字体大小)
- 中 (UI 字体大小)
- 大 (UI 字体大小)

### 视图标题字体粗细

目标 CSS 变量: `var(--file-header-font-weight)`

默认: 400
