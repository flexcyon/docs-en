### 内联标题颜色

目标 CSS 变量: `var(--inline-title-color)`

默认: Normal text (默认文本颜色) (变量选项)

选项:

* Cyan (青色)
* Blue (蓝色)
* Purple (紫色)
* Pink (粉红色)
* Red (红色)
* Orange (橙色)
* Yellow (黄色)
* Green (绿色)
* Accent (强调色)
* Normal text (默认文本颜色)

### 行内标题字体大小

目标 CSS 变量: `var(--inline-title-size)`

默认: 1.802 (em)

### 行内标题字重

目标 CSS 变量: `var(--inline-title-weight)`

默认: 700

### 行内标题行高度

目标 CSS 变量: `var(--inline-title-height)`

默认: 1.2

### 不显行内标题

目标 CSS 类: `var(--flexcyon-no-inline-title)`

默认: false (类切换)
