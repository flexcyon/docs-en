---
title: 工具与软件
---

以下工具和软件是制作主题不可或缺的及其文件.

### 基础应用程序

- [Obsidian](https://obsidian.md/zh/): 此主题所针对的 Markdown 编辑器.

### Web 技术

- [CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS): 用于设计界面样式.

- [SCSS](https://sass-lang.com/): CSS 预处理器, 在 [MIT 许可下](https://github.com/sass/dart-sass/blob/main/LICENSE).

- [Stylelint](https://stylelint.io/): CSS/SCSS 代码 linter, 在 [MIT 许可下](https://github.com/stylelint/stylelint/blob/main/LICENSE).

### 文本编辑器

- [Vim](https://www.vim.org/): [Vim 许可](https://github.com/vim/vim/blob/master/LICENSE) 下的模态文本编辑器.

- [Neovim](https://neovim.io/): [Apache 2.0 许可](https://github.com/neovim/neovim/blob/master/LICENSE.txt) 下的现代 Vim 替代方案.

- [VS Code](https://code.visualstudio.com/): 大多数人都同意的一个理智的默认代码编辑器, 根据 [MIT 许可证](https://github.com/microsoft/vscode/blob/main/LICENSE.txt) 授权.

### 版本控制

- [Git](https://git-scm.com/): 开发人员使用的事实上的版本控制系统 (VCS). 根据 [GPLv2 许可证](https://github.com/git/git/blob/master/COPYING) 授权.

- [GitHub](https://github.com): 托管源代码的 `git` 服务器.

- [GitHub Pages](https://docs.github.com/zh/pages): GitHub 提供的静态网站托管.

### 文档

- [Hugo](https://gohugo.io/): 使用 Golang 的漂亮静态站点生成器. 根据 [Apache 2.0 许可证](https://github.com/gohugoio/hugo/blob/master/LICENSE) 授权.

- [Hugo Hextra](https://imfing.github.io/hextra/zh-cn/): 整洁的 Hugo 主题, 具有健全的默认设置. 根据 [MIT 许可证](https://github.com/imfing/hextra/blob/main/LICENSE) 授权.

- [flexsearch](https://github.com/nextapps-de/flexsearch): 幕后使用的文本搜索库. 根据 [Apache 2.0 许可证](https://github.com/nextapps-de/flexsearch/blob/master/LICENSE) 授权.

#### 迁移工具

- [Pyodide](https://pyodide.org/en/stable/): 用于在 Web Assembly (WASM) 中运行 Python. 根据 [Mozilla 公共许可证 2.0](https://github.com/pyodide/pyodide/blob/main/LICENSE) 授权.

- [yace](https://yace.solopov.dev/): 小于 2KB 的浏览器代码编辑器, 根据 [MIT 许可证](https://github.com/petersolopov/yace) 授权.

### 字体

- [Cascadia Code](https://github.com/microsoft/cascadia-code) 是一种有趣的新等宽字体
包括编程连字, 旨在增强现代外观和感觉 Windows Terminal.

字体根据 [SIL Open Font License](https://openfontlicense.org) 获得许可.

- [Departure Mono](https://departuremono.com) 是 Helena Zhang 的等宽像素字体.

字体根据 [SIL Open Font License](https://openfontlicense.org) 获得许可.

- [Maple Mono](https://github.com/subframe7536/Maple-font) 是一种开源的等宽字体
IDE 和 Terminal 具有圆角, 连字和 Nerd 字体图标，细粒度定制选项.

其中英文完美 2:1 对齐的特点使字体能够在多语言等场景中实现整洁, 统一, 美观, 舒适
的外观显示和 Markdown 表格.

字体根据 [SIL Open Font License](https://openfontlicense.org) 获得许可.
