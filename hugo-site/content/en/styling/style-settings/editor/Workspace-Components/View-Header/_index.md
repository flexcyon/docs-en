## Configuration Options

### View header breadcrumb max width

CSS Variable(s) targeted: `var(--flexcyon-view-header-breadcrumb-max-w)`

Default: 12.5 (vw)

### Mode View Header Title Vertical Padding

Vertical padding of View header title in modes like Angled and Powerlevel10k.

CSS Variable(s) targeted: `var(--flexcyon-mode-view-header-title-verti-padding)`

Default: 4 (px)

### Mode View Header Title Horizontal Padding

Horizontal padding of View header title in modes like Angled and Powerlevel10k.

CSS Variable(s) targeted: `var(--flexcyon-mode-view-header-title-horiz-padding)`

Default: 12 (px)

### View Header Text Justification

CSS Variable(s) targeted: `var(--file-header-justify)`

Default: Center (variable select)

Options:

- Start
- Center
- End
- Flex Start
- Flex End
- Left
- Right
- Normal
- Space Between
- Space Around
- Space Evenly
- Stretch

### View Header Font Size

CSS Variable(s) targeted: `var(--file-header-font-size)`

Default: Small UI Font size (variable select)

Options:

- Smaller UI Font size
- Small UI Font size
- Medium UI Font size
- Large UI Font size

### View Header Font Weight

CSS Variable(s) targeted: `var(--file-header-font-weight)`

Default: 400
