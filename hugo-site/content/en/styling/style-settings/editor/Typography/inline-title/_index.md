### Inline Title Colour

CSS Variable(s) targeted: `var(--inline-title-color)`

Colour of inline title.

Default: Normal text (variable select)

Options:

* Cyan
* Blue
* Purple
* Pink
* Red
* Orange
* Yellow
* Green
* Accent
* Normal text

### Inline title font size

CSS Variable(s) targeted: `var(--inline-title-size)`

Default: 1.802 (em)

### Inline title font weight

CSS Variable(s) targeted: `var(--inline-title-weight)`

Default: 700

### Inline title line height

CSS Variable(s) targeted: `var(--inline-title-height)`

Default: 1.2

### Do not display inline title

CSS Classe(s) targeted: `var(--flexcyon-no-inline-title)`

Default: false (class toggle)
