# Usage

Adds repeating polka dots pattern to your editor background. Size can be adjusted in style settings.

```md
cssclasses:
    - editor-circle
---

Your content will render as usual
```

## Callout metadata provider

There is also a callout metadata provider for circle background (which works in
live preview and reading mode)

```md
>[!note|bg-circle] I will display as usual
> I will have a polka dot pattern background
```
