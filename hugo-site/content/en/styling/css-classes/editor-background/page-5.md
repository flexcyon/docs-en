# Usage

Adds repeating checkerboard pattern to your editor background. Size can be adjusted in style settings.

```md
cssclasses:
    - editor-chess
---

Your content will render as usual
```

## Callout metadata provider

There is also a callout metadata provider for chess background (which works in
live preview and reading mode)

```md
>[!note|bg-chess] I will display as usual
> I will have a dotted background
```
