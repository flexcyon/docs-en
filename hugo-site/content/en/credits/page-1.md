---
title: Tools and Software
---

The following tools and software were indispensable in the making of the theme
and its documentation.

### Base application

- [Obsidian](https://obsidian.md/): The markdown editor for which this theme is made for.

### Web Technologies

- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS): Use to style the interface

- [SCSS](https://sass-lang.com/): CSS preprocessor, under the [MIT license](https://github.com/sass/dart-sass/blob/main/LICENSE).

- [Stylelint](https://stylelint.io/): CSS/SCSS linter, under the [MIT license](https://github.com/stylelint/stylelint/blob/main/LICENSE).

### Text Editors

- [Vim](https://www.vim.org/): Modal text editor, under the [Vim License](https://github.com/vim/vim/blob/master/LICENSE).

- [Neovim](https://neovim.io/): Modern vim alternative, under the [Apache 2.0 License](https://github.com/neovim/neovim/blob/master/LICENSE.txt).

- [VS Code](https://code.visualstudio.com/): Sane default code editor most can agree on, under the [MIT License](https://github.com/microsoft/vscode/blob/main/LICENSE.txt).

### Version Control

- [Git](https://git-scm.com/): De facto version control system (VCS) used by developers. Licensed under the [GPLv2 License](https://github.com/git/git/blob/master/COPYING).

- [GitHub](https://github.com/): Git server where the source code is hosted.

- [GitHub Pages](https://docs.github.com/en/pages): Static site hosting provided by GitHub.

### Documentation

- [Hugo](https://gohugo.io/): Nice static site generator which uses Golang. Licensed under the [Apache 2.0 License](https://github.com/gohugoio/hugo/blob/master/LICENSE)

- [Hugo Hextra](https://imfing.github.io/hextra/): Neat Hugo theme with sane defaults. Licensed under the [MIT License](https://github.com/imfing/hextra/blob/main/LICENSE)

- [flexsearch](https://github.com/nextapps-de/flexsearch): Text search library used under the hood. Licensed under the [Apache 2.0 License](https://github.com/nextapps-de/flexsearch/blob/master/LICENSE).

#### Migration Tool

- [Pyodide](https://pyodide.org/en/stable/): used to run Python in Web Assembly (WASM). Licensed under the [Mozilla Public License 2.0](https://github.com/pyodide/pyodide/blob/main/LICENSE).

- [yace](https://yace.solopov.dev/): under 2KB code editor for browser. Licensed under the [MIT License](https://github.com/petersolopov/yace).

### Fonts

- [Cascadia Code](https://github.com/microsoft/cascadia-code) is a fun, new monospaced font
that includes programming ligatures and is designed to enhance the modern look and feel
of the Windows Terminal.  

It is licensed under the [SIL Open Font License](https://openfontlicense.org)

- [Departure Mono](https://departuremono.com) is a monospaced pixel font by Helena Zhang.

It is licensed under the [SIL Open Font License](https://openfontlicense.org)

- [Maple Mono](https://github.com/subframe7536/Maple-font) is an open source monospace font
with round corner, ligatures and Nerd-Font icons for IDE and terminal, fine-grained
customization options.

Its characteristic of perfect 2:1 alignment between Chinese and English allows the font to
achieve a neat, uniform, beautiful, and comfortable appearance in scenarios such as multilingual
display and Markdown tables.

It is licensed under the [SIL Open Font License](https://openfontlicense.org)
